# 🌍 Wanderlust

A full-stack travel accommodation platform inspired by Airbnb, where users can explore destinations, create property listings, upload images, leave reviews, and discover places through interactive maps.

## 🚀 Live Demo

👉 https://wanderlust-project-8xq5.onrender.com

## ✨ Features

- User Authentication & Authorization
- Create, Edit & Delete Listings
- Image Uploads with Cloudinary
- Reviews & Ratings System
- Search Listings by Location/Title
- Category-Based Filters
- Interactive Maps with Mapbox
- Responsive Design

## 🛠️ Tech Stack

**Frontend:** EJS, HTML, CSS, Bootstrap, JavaScript

**Backend:** Node.js, Express.js

**Database:** MongoDB Atlas, Mongoose

**Services:** Cloudinary, Mapbox

**Authentication:** Passport.js

## 📦 Installation

```bash
git clone https://github.com/Pranali379/wanderlust-project.git
cd wanderlust-project
npm install
npm start
```

Visit:

```bash
http://localhost:3000
```
